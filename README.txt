Psych Engine Java / TeaVM 配布物

Desktop:
  java -jar psych-java-with-assets.jar
  Java 17+ required.

TeaVM JS/Wasm:
  cd teavm
  python3 -m http.server 8080
  Open http://localhost:8080/index-js.html or index-wasm.html.
  Do not open the HTML with file://.

The TeaVM JS and Wasm builds completed successfully. Assets are shared once
under teavm/assets/.
